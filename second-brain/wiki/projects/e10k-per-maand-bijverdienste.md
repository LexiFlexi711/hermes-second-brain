# €10.000/maand Bijverdienste

## Context

Lexi heeft dringend een substantiële bijverdienste nodig. **Minimaal €10.000/maand.** 
Dit is geen experiment of speeltje — het is existentieel. Ze kan het zich permitteren 
om op te bouwen, maar niet om stil te staan.

## Huidige Setup

- Crypto tradebot met 5 strategieën (V1, V2, V3, momentum, range)
- V2 is beste kandidaat (48.9% WR, +4.96% PnL over 2jr backtest)
- Geen enkele strategie levert momenteel consistente winst in live trading
- Server met 25 Docker containers, 8 cores, 16GB RAM

## Aanpak

Elke actie, elk project, elke verbetering moet bijdragen aan dit doel.

Mogelijke richtingen om te verkennen:
1. **Crypto trading optimaliseren** — V2 grid search voor verliesgevende pairs
2. **Auto-restart** — systemd services zodat traders nooit uitliggen
3. **Nieuwe strategieën** — andere markten, andere aanpak
4. **Bredere inkomsten** — webdesign, automatisatie, consulting (niet enkel crypto)
5. **Kosten besparen** — overbodige services uitschakelen (bv. Langfuse)
