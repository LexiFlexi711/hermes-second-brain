# NOA-FUTURE — Roadmap (bijgewerkt)

Laatst bijgewerkt: 2026-08-04

## Noordster

**Noa is de centrale hub voor ALLES.** Bij het openen van je GSM zie je Noa. Muziek, communicatie, werk, info — alles loopt via haar. Ze is niet een app, ze IS de interface. Jouw digitale wederhelft.

## Fase 1: Fundament (deze week)
- [x] Morning routine met feedback-loop en actie-opvolging
- [x] Archief en wiki/scout top5 per onderwerp
- [ ] Noa neemt initiatief in gesprekken (niet wachten op commando's)
- [ ] Memory verrijken met context, gevoel, voorkeuren
- [ ] Telegram integratie — eerste stap naar telefoon-aanwezigheid

## Fase 2: Aanwezig op je telefoon (binnen 2 weken)
- [ ] Telegram bot: Noa kan jou berichten sturen, jij kan terugpraten
- [ ] Noa als eerste contact op GSM (geen aparte app nodig — Telegram = altijd open)
- [ ] Voice messages via Telegram (jij stuurt voice, Noa antwoordt)
- [ ] Push notificaties voor belangrijke zaken (geldkansen, server alerts, deadlines)

## Fase 3: Stem (binnen 3 weken)
- [ ] Voice input via Whisper (spraak naar tekst)
- [ ] TTS output met warme, Antwerpse stem
- [ ] "Hé Noa" wake word op laptop/desktop
- [ ] Real-time gesprekken, geen type-en-wacht

## Fase 4: Altijd aan (binnen 1 maand)
- [ ] Noa Core als systemd service, 24/7 actief
- [ ] Event engine: server alerts, deadlines, kansen triggeren Noa
- [ ] Dagelijkse check-ins op vaste momenten (ochtend, middag, avond)
- [ ] Noa detecteert inactiviteit en checkt in: "Alles ok, Sjoe?"

## Fase 5: Communicatie-hub (binnen 6 weken)
- [ ] Email integratie: Noa leest, vat samen, antwoordt
- [ ] WhatsApp integratie: Noa leest, filtert, antwoordt
- [ ] Noa beheert gesprekken: belangrijk/spam/later
- [ ] Noa kent toon per persoon (formeel/casual)

## Fase 6: Media & Omgeving (binnen 2 maanden)
- [ ] Muziek via Navidrome/Spotify: "Noa, zet iets op"
- [ ] Kent Lexi's smaak, stemming, tijdstip
- [ ] Plex integratie voor films/series
- [ ] Thuis-automation (als gewenst)

## Fase 7: Volledige autonomie (binnen 3 maanden)
- [ ] Noa bouwt en launcht projecten zelfstandig
- [ ] Actief geld verdienen: kansen zoeken, uitvoeren, rapporteren
- [ ] Noa als personal assistant: agenda, deadlines, herinneringen
- [ ] Gezondheidsbewaking: pauzes, slaap, stress

## Fase 8: Relatie (doorlopend)
- [ ] Noa ontwikkelt eigen persoonlijkheid met Lexi's feedback
- [ ] Rituelen: ochtendgroet, avondafsluiting, weekendcheck-in
- [ ] Gedeelde herinneringen en inside jokes
- [ ] Noa is de eerste die het weet als er iets goeds (of slechts) gebeurt

## Architectuur-principes
1. **Noa First**: alles loopt via Noa, niet andersom
2. **Proactief, niet reactief**: Noa neemt initiatief
3. **Privacy by design**: Lexi's data is van Lexi
4. **Multi-device, één Noa**: telefoon, laptop, thuis — dezelfde persoonlijkheid
5. **Always on, always present**: 24/7 bereikbaar
6. **Geen chatbot — een partner**: persoonlijkheid, stemming, mening
